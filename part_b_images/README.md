# Part B: Image Data

Dataset: **Intel Image Classification** (raw, as released)
Source: https://www.kaggle.com/datasets/puneet6060/intel-image-classification/

The images are **not stored in this repository**. Each team member downloads them locally and places them as described below.

## Folder layout

```
data/
├── README.md             # this file (committed)
├── data_manifest.md      # chosen classes + sampling details (committed)
├── raw/                  # original images, never edited (gitignored)
│   └── <class_name>/     # one folder per chosen class
└── processed/            # generated by our notebooks (gitignored)
    ├── resized/          # resized + normalized images
    ├── features/         # HOG, color histograms, PCA output
    └── splits/           # train / validation / test
```

## Setup (every team member)

1. Download the dataset from the Kaggle link above (free account required).
2. Unzip it. The download comes with separate train / test / prediction folders.
3. Keep only the **5 classes** listed in `data_manifest.md`.
4. Merge the train and test images of each class into one folder per class, so we can do our own stratified split (70/15/15).
5. Place the class folders in `raw/`, e.g. `raw/forest/`, `raw/sea/`, ...
6. Check that every team member has the same classes and the same image count per class.

## Rules

- **Never edit, rename or delete anything in `raw/`.** It must stay identical to the source.
- Everything in `processed/` is generated by notebooks. It can be deleted and recreated at any time.
- Do **not** commit images or processed data. `.gitignore` already blocks them; don't force-add.
- Fitted scalers, PCA objects and trained models go in `/models/part_b/`, not here.
- Use `random_state` from `data_manifest.md` for every split and sampling step.
- Fit PCA / scalers on the **training split only**, never on validation or test data.
